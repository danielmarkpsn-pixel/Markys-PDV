# UNISTALL — Recuperação do Master

Esta pasta será destinada à ferramenta de recuperação da conta Master.

## Regras de segurança
- Não armazenar senhas, tokens ou códigos reais neste repositório.
- O código de recuperação deverá ser configurado pelo proprietário fora do Git e armazenado no banco somente como hash.
- A ferramenta deverá limitar tentativas, auditar o evento sem registrar o código e invalidar/rotacionar o código após o uso.
- A recuperação não poderá permitir criar uma segunda conta Master.

Implementação pendente. Nenhuma credencial está configurada aqui.
